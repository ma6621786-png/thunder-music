# THUNDER MUSIC — Android starter project

This is a Flutter starter project for building an Android APK with GitHub Actions.
It is **not yet the complete feature set** requested. It currently provides a dark
music-player interface and a build workflow. Device media scanning, VidMate import,
downloads, provider integrations, playlists persistence, and full background playback
still need implementation and testing.

## Build on GitHub
1. Upload the contents of this folder to the root of your `thunder-music` repository.
2. Open the repository's **Actions** tab.
3. Enable Actions if GitHub asks.
4. Run the workflow named **Build Android APK** (or push a commit).
5. Open the completed workflow run and download `thunder-music-debug-apk` from Artifacts.

The APK produced by this starter is a debug APK for sideloading.
